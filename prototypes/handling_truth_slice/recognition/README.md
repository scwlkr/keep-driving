# Recognition evidence harness

This is a human-operated evidence tool for the frozen Desktop Truth Slice A candidate. It records raw answers; it does not count an automated or agent run as a participant.

Run from a clean candidate checkout with a unique pseudonymous participant/session and deterministic seed:

```sh
repo=/Users/shanewalker/Desktop/dev/keep-driving
candidate="$repo/proofs/handling_truth_slice/ticket-08/candidate.json"
previews="$repo/proofs/handling_truth_slice/ticket-08/recognition/KD08-HM-01-previews"
/opt/homebrew/bin/godot --path "$repo" --resolution 896x414 res://prototypes/handling_truth_slice/recognition/recognition_harness.tscn -- --recognition-candidate=FULL_GIT_SHA --recognition-candidate-file="$candidate" --recognition-participant=KD08-HM-01 --recognition-session=KD08-HM-01-preview --recognition-preview-only --recognition-preview-dir="$previews"
/opt/homebrew/bin/godot --path "$repo" --resolution 896x414 res://prototypes/handling_truth_slice/recognition/recognition_harness.tscn -- --recognition-candidate=FULL_GIT_SHA --recognition-candidate-file="$candidate" --recognition-participant=KD08-HM-01 --recognition-session=KD08-HM-01-recognition --recognition-preview-manifest="$previews/manifest.json" --recognition-output="$repo/proofs/handling_truth_slice/ticket-08/recognition/KD08-HM-01.jsonl"
```

The candidate and output must use the exact canonical repository paths shown above, and the output must not already exist. Before opening it, the harness verifies the candidate contract generated by `scripts/freeze_handling_truth_slice_candidate.sh`: clean source/export SHA, full host/session/package freeze, running-engine identity, embedded provenance, executable/PCK hashes, current asset manifest, playtest contract, recognition harness, export preset, matching Git HEAD, and no tracked source edits. The seed is derived from the frozen candidate SHA plus participant slot. Each session contains one positive, one target-absent near-neighbor, and one blank trial for each of the 15 frozen categories: hero car, three isolated route classes, landmark, safehouse, objective, threat, Fuel, repair, cargo, reward, and three obstacle weights. Every 500 ms exposure starts after its first completed draw, counts exactly 30 `frame_post_draw` completions, records the completed hide draw and full timestamp trace, and matches its retained preview; every response times out after ten seconds.

Run the non-human contract self-test with:

```sh
/opt/homebrew/bin/godot --headless --path /Users/shanewalker/Desktop/dev/keep-driving --script res://prototypes/handling_truth_slice/recognition/recognition_contract_test.gd
```

Named human evidence owners must validate sessions and aggregate the frozen ten-person cohort under `PLAYTEST_EVIDENCE.md`; this harness never makes the gate pass by itself.
